# Rule-Based AI Chatbot

A simple console-based rule-based chatbot developed using Python as part of my Artificial Intelligence Internship at DecodeLabs.

## Description

This chatbot interacts with the user through the command line and provides predefined responses based on the user's input.

The project focuses on understanding basic programming logic and how a simple rule-based conversational system works.

## Features

- User input handling
- Greeting responses
- Basic question and answer functionality
- Help command
- Thank-you responses
- Exit functionality
- Continuous conversation using a loop
- Colored terminal interface

## Technologies Used

- Python
- Colorama

## Concepts Used

- `if`, `elif`, and `else`
- `while` loop
- String handling
- User input
- Conditional logic
